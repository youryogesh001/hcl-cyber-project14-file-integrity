# Project 14: File-Integrity Verification
HCL Cybersecurity Curriculum — B.Tech 2nd Year

## Overview
Recorded baseline SHA-256 hashes for lab files (`config.txt`, `users.txt`, `audit.log`), simulated expected and unexpected modifications, and verified integrity against the baseline.

## Contents
- `baseline.sha256` (or `baseline_hashes.csv`) — Original baseline hash record
- `config.txt`, `users.txt`, `audit.log` — Lab test files
- `ss1_setup.png` to `ss4_verification.png` — Terminal execution screenshots
